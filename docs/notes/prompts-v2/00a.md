WHAT THIS BOARD IS FOR
This is the first design work for Pantopus and comes before any screen. Every later screen prompt names these nine components exactly, and each screen is designed in a separate project with no memory of this one. Once the founder accepts this board, the founder adds the components to the published Pantopus design system (see PUBLISH). That is the only way the same component comes out identical on 59 surfaces. So draw each component once, precisely, with every variant and every state listed in this prompt, and label everything with its exact name, its keys (B18) and its token names. Everything you need is written in this prompt; you do not need any other document.

B1. Artboard format. Every artboard is 1440 px wide and as tall as its content needs. Its background is surface.app (light) or dark surface.app (dark). Artboard names on this board follow "00a · <Component> · <NN-state> · <light|dark>": the component name takes the place of the house style's platform slot, because one specimen artboard shows all three platforms (this is recorded on Notes). Above the frame, print the exact artboard name from the ARTBOARDS manifest as a visible label in label 13/18/600 text.strong. Inside the frame, the top block is: the component name in h1 30/36/700 text.primary, its one-line purpose in body 16/24 text.secondary, then the "Used in" line in caption 12/16 text.secondary, printed exactly as this prompt gives it (a list of surface ids, or for OfflineNotice the sentence given there). Below that come the sections this prompt lists for that artboard, each with an overline 11/16/600 caps heading (for example "ANATOMY", "VARIANT × STATE", "AX5 AND 200%", "GREYSCALE", "INCREASE CONTRAST", "ACCESSIBILITY", "COPY", "PLATFORMS", "IN CONTEXT", "INSTEAD OF").

B2. Specimen cells. Draw each specimen on a surface.base card (radius lg 12, shadow sm, 16 px padding) unless the cell says it sits on raised, sunken or app. Under each specimen, print a caption 12/16 text.secondary line naming the cell by its keys (B18), for example "official · default · S 16pt · on surface.base".

B3. Callouts. Draw anatomy callouts as 1 px text.secondary leader lines ending in a numbered SQUARE badge (16×16, radius xs 4, surface.sunken fill, label 13/18/600 text.strong numeral). Next to each number, give the measurement and the token name in caption 12/16 text.strong, for example "① 12pt disc · ink text.secondary". Use square badges on purpose: circles and rings are reserved for ProvenanceMark (B8). Draw dimension lines as 1 px text.secondary with 4 px end ticks and the number centred on the line.

B4. Units and sizes. Give every size three ways the first time it appears in a section: "pt (iOS) / dp (Android) / px (web)". The values are equal, for example "16pt / 16dp / 16px". Spacing, padding and gaps use only the 4-px spacing scale (4, 8, 12, 16, 20, 24, 32, 40, 48, 64). Type uses only the type scale, plus the AX5 and 200% sizes listed in B9 and the one weight deviation recorded on Notes (KindGlyph's selected tile label). B8. Circles are reserved. Only ProvenanceMark may draw a solid disc, a ring, or a disc with a knocked-out tick. This rule applies to a glyph's whole silhouette and to drawn standalone dots, bullets and badges: no other component, annotation, bullet, badge, status glyph or decoration uses a plain solid circle or plain ring as its shape. The typographic middle dot (·) in text is allowed; this rule covers drawn shapes only. Round sub-parts inside a larger glyph are fine (a person's head, cart wheels, a map pin's hole); draw them as parts, not as free-standing dots. Groups of dots inside a glyph are drawn as short dashes or small rounded squares. The only exceptions are platform radio indicators, in exactly two places, each flagged on Notes:
  - KindGlyph's selected tile, on every platform: a ring with a filled centre in the tile corner. Unselected tiles show no indicator.
  - Android Material 3 radio buttons in the 200% one-column lists (KindGlyph and ChoiceChip), where they are the platform control: a ring with a filled centre when selected, an empty ring when unselected.
  On iOS (AX5) and web (200% zoom), the one-column lists use no ring at all: the selected row gets a trailing check stroke, as native iOS list selection does, and unselected rows get nothing.

B9. Large text. AX5 frames (iOS) use these sizes: caption 12 → 40pt, label 13 → 44pt, bodySmall 14 → 46pt, body 16 → 53pt. Android 200% frames use caption 24sp, label 26sp, bodySmall 28sp, body 32sp. At both: pairs stack vertically, text wraps and never ends in an ellipsis, pills that must wrap become rounded rectangles (radius lg 12), and hit areas grow with the content. Glyphs and marks scale with the text beside them, capped at 2× their default size (XS 12 → 24, S 16 → 32, M 24 → 48; L 56 does not scale). Draw AX5 frames at 393 pt wide and 200% frames at 412 dp wide, cropped to the component and its row. Web 200% zoom frames are 390 px wide at 200% browser zoom, which is a 195 px effective viewport, so they always show the narrowest layout; where a component also needs its wide zoomed form, this prompt asks for a separate 1440-wide frame at 200% zoom (720 px effective), cropped to the component.

B10. Greyscale. Each light 03 artboard includes a GREYSCALE section: the light variant × state grid again at 50% scale, fully desaturated (0% saturation). Two exceptions: ProvenanceMark's 03 does not redraw its grid, because its 02 grid already has a greyscale column (03 points to that column and adds the WRONG example), and KindGlyph's 03 shows a representative subset (the 17 row-variant glyphs plus the whole of Part B). Next to every cell, print either "Reads without colour: yes — <the non-colour cue>" or, where this prompt names a fail, the fail and its fix.

B11. Fixtures. Use only the house-style FIXTURES and the strings quoted in this prompt. TODAY is Mon 19 Oct 2026, 6:10 PM Pacific. Every relative time on this board is computed from that moment (for example, "observed 7:00 AM" is "11 hours ago"; Mon 26 Oct is "in 7 days"; Sat 10 Oct is "9 days ago"). Every date row on this board follows one format: the relative count first and then the weekday date ("in 4 days · Fri 23 Oct"); "Tonight", "Today" and "Tomorrow" stand alone; a headline naming tomorrow's pickup may show the weekday date alone. Any string that is not in the house style and not quoted in this prompt must be listed on 00a · Notes.

B12. Variant × state grids. Rows are the variants listed in this prompt, in the order given. Columns are the states listed in this prompt, in the order given. Draw every cell. Where this prompt says a cell "does not apply", draw the cell with an empty surface.base card and the words "Does not apply — <reason>" in caption 12/16 text.secondary. Where a row gives one reason for several cells, print that same reason in each of them. Do not leave any cell blank without text, and do not skip a row or column.

B13. Targets. The minimum hit area is 44pt on iOS, 48dp on Android (with 8dp gaps) and 44px on web. This prompt calls that size "target (B13)". Draw hit areas as a 1 px dashed text.secondary outline labelled "target 44pt / 48dp / 44px". Wherever a mark or glyph sits inside a row, also draw a small "not a target" label pointing at the mark.

B14. Focus vs selection. Focus is always a 2 px border.focus ring (dark: dark border.focus) with a 2 px gap outside the control's shape. Selection is always a fill plus a glyph plus a visible edge where stated (and a weight or ink change where stated). Never show selection with a ring alone, and never show focus with a fill.

B15. Motion. No component on this board animates, except the FreshnessLine hairline (component 4). That hairline is the platform's own system indeterminate progress indicator, with no custom duration; it is shown for at most 5s. It is exempt from the house style's 300ms limit because it is a progress indicator, not a transition, and it obeys the house style's "idle loops stop within 5s" instead (recorded on Notes). Where motion exists, draw its Reduce Motion pose and its end pose next to it.

B16. Increase Contrast. Each 03 artboard (light, and ProvenanceMark's dark 03) has an INCREASE CONTRAST section: either a frame showing what changes, or the sentence "Increase Contrast: nothing changes — <why>". The general rule is that text.secondary ink becomes text.strong (dark: dark text.strong); text.muted on disabled controls stays text.muted, because the disabled reason caption carries the meaning. Each component section below states its own result.

B17. Air readings and the AQI track. Air rows on this board (ProvenanceMark R5, SourceCaption R2 and its in-context crop, FreshnessLine R5, OfflineNotice R1) show the value line and caption only. The AQI track belongs to AqiBand, which is not on this board, so no EPA ColorVision Assist hue appears anywhere here and no text ever sits on an AQI fill. Label one air crop "track omitted: AqiBand".

B18. Keys. Every grid row and every grid column carries a short printed key: lowercase, hyphenated, with no "/" and no spaces, printed in caption 12/16 text.secondary as "key: <key>" under its label. Row and column labels may be longer and may quote fixture strings, but the key never contains a fixture string or a date. The keys for each grid are listed in that component's section. The publish names on Notes (section E) use only these keys.

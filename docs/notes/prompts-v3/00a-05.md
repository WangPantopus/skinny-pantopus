INSTEAD OF (print on 01-anatomy)
- Instead of a full-page offline illustration, keep the cached screen readable with the offline line on top — because people still need what they already had.
- Instead of silent dead buttons, disable the control and put the reason under it — because a button that does nothing looks broken.
- Instead of a red or amber banner, use plain or surface.sunken with text.strong — because being offline is a condition, not an error.
- Instead of blanking stale data, keep it with "as of 7:04 AM" — because a blank throws away true information.
- Instead of "You're offline" twice in a row, let the offline line open and the next sentence say what still works — because the repeat adds nothing.

LINK RULE (applies to every cell, crop and frame)
A caption is a link only when its source has a URL. A link caption shows all three of these: the authority word in primary.700 (dark: primary.400 (dark link)) with an underline; the trailing external-link glyph in the same colour; and the dashed target (B13) around the caption line. A caption with no URL is all text.secondary (text.strong on sunken), with no underline, no glyph and no target.

ACCESSIBILITY (print on 01-anatomy)
- Contrast is at least 4.5:1 (see the table).
- The caption is read after the value in the row's merged label: "Air quality, AQI 42, Good, AirNow, nearest monitors, observed 7:00 AM today, official".
- When a URL exists, the row exposes the link as a custom action named "Open <authority>" (for example "Open AirNow"). On web, the link is a separate focusable link after the row.
- The non-colour cue for a link is the underline plus the external-link glyph.
- Target rule: a caption is a target (B13) only when a URL exists. A caption with no URL is never a target.
- There is no hover-only content.

COPY (print on 01-anatomy)
- Always authority · scope · as-of (as-of where the source has one).
- Use the authority's own word, "hazard" or "potential"; never "risk" unless the source says risk.
- Deadlines received by a date say "must arrive by" ("Online or mail voter registration must arrive by Mon 26 Oct").
- Never write "Sources:" at widths above 360 (except the OG image).
- Never write "provider", "feed" or "partner" for the source.
- Never label a frozen reading "today".

INSTEAD OF (print on 01-anatomy)
- Instead of hiding the source behind a tooltip or "learn more", print authority · scope · as-of on the value — because almost nobody opens the sheet.
- Instead of labelling a frozen reading "today", write "on Sat 12 Sep 2026" — because a shared card is read days later.
- Instead of making a caption with no URL tappable, draw it flat — because a target that goes nowhere breaks trust.
- Instead of "Sources:" on wide layouts, give every row its own caption — because the collapsed line exists only for 320–360 widths (except the OG image).
- Instead of cutting a long authority short with an ellipsis, wrap to a second line — because the authority is the caveat.
- Instead of a hollow mark on a county-wide official estimate, use the filled mark and the scope word — because hollow means "not confirmed".

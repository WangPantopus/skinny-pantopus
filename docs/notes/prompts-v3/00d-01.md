INSTEAD OF
- Instead of "All caught up", "Inbox zero" or "You're all set", draw the heading with the four checks — because people need to see what was checked, not a mood.
- Instead of the heading while a provider is loading, draw S2 — because an early all-clear teaches people to stop trusting it.
- Instead of an illustration or keeper pose, draw the plain card — because silence is a fact, not a celebration.
- Instead of ticks in circles, draw bare check strokes — because filled vs hollow means provenance.
- Instead of "Something went wrong", draw "Couldn't reach AirNow · Retry" — because a failed check names its provider.

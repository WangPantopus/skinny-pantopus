ACCESSIBILITY (print on 01-anatomy)
- Selection is shown by check, fill and outline, not colour alone. The focus ring is separate from selection.
- R1, R2, R3 and R5 are radio groups. iOS: buttons with the selected trait ("7:00 AM, selected, 2 of 4"). Android: selectable semantics ("7:00 AM, selected"). Web: role="radiogroup" with role="radio" and aria-checked; arrow keys move between chips.
- R4 is not a radio group; it is a toggle. Web: a button with aria-pressed. iOS: a button with the selected trait. Android: toggleable semantics. Spoken: "Photographed, off" / "Photographed, on".
- Disabled chips stay focusable and read their reason.
- Targets: a target (B13) around the 32 visual, with 8pt gaps.

COPY (print on 01-anatomy): Sentence case; exact strings as in the grid. Times are written "7:00 AM" (space, capital AM), never "6:00pm" or "7:40 am".

PLATFORMS (print on 01-anatomy): iOS: R5 is the native segmented control; R1–R4 are Pantopus chips. Android: Material 3 filter chips with the pill radius; R5 is a single-select chip row. Web: :focus-visible ring, no hover-only affordance. Large text: trailing-check rows on iOS and web; Material 3 radios on Android.

INSTEAD OF (print on 01-anatomy)
- Instead of a ChoiceChip as a status badge, use StatusChip — because a choice chip looks tappable.
- Instead of a status chip on a person, write the role in plain text — because people are not statuses.
- Instead of a border token as any chip's only edge, use text.secondary (unselected) or text.muted (disabled) — because an input's edge must be visible.
- Instead of a selected chip bounded only by its 1.07:1 fill, add the 1px primary.700 outline — as AddressChip's selected edge does.
- Instead of the focus ring doubling as selection, keep the ring for focus and fill + check + outline for selection — because they are different states.
- Instead of truncating long labels at large text, switch to one-column rows — because truncated choices cannot be told apart.
- Instead of an empty-ring radio on iOS or web rows, use a trailing check on the selected row — because iOS has no radio control and an empty ring is the unconfirmed mark's shape.
- Instead of disabling a segment that still has cached content, disable only the segments that need a connection — because the reason must match what is disabled.

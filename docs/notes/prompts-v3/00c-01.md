# Foundations 00c-01 — DateRow
id: 00c-01 · clean: True · artboards: 6

Component 00c-01: DateRow. Follow the board rules from the setup message.

PUBLISH NAME: DateRow. This message is the complete DateRow specification.

PURPOSE (print at the top of 01). One dated fact in a list. Its row grammar is shared by the 14-day strip list, the calendar agenda, the place file Dates section and reminder rows.

USED IN (panel): f5-today-calendar-strip · f3-household-calendar · x-place-file · x-date-sheet · f3-household-notifications · f7-today-widget.

EXTRA STAND-INS FOR THIS COMPONENT (label each "stand-in", per R11)
- KindGlyph: a 24pt line icon with a 2pt stroke in text.strong, with one distinct drawing per kind: garbage, recycling, garbage+recycling, notice deadline, warranty ends, HOA dues, property-tax due, property-tax appeal, voter registration. Never one generic calendar icon.
- SourceCaption: caption 12/16 text.secondary, "authority · scope · as-of". It wraps and never ellipsises the authority.

ANATOMY (01-anatomy)
Draw V3a at 2x for callouts ①–⑦ and ⑩. Beside it, draw V3c in S3 (done) at 2x for callouts ⑧ and ⑨.
① Row: minimum height 56pt, padding 16pt horizontal and 12pt vertical, on surface.base. The whole row is the target: draw the dashed target rectangle around it.
② Leading KindGlyph, 24pt, text.strong, top-aligned with the title, with a 12pt (spacing.3) gap after it.
③ Title: body 16/24/400, text.primary. It wraps and is never truncated.
④ Line 2: caption 12/16 text.secondary, the relative date then the absolute date, e.g. "in 4 days · Fri 23 Oct". "Tonight", "Today" and "Tomorrow" stand alone, with no absolute date after them. An approximate date reads "about Dec 2026".
⑤ SourceCaption short form (authority · scope). It continues line 2 after a middot, or wraps to line 3.
⑥ Trailing ProvenanceMark S (16pt), vertically centred, with 8pt (spacing.2) between it and the text. It is not a target.
⑦ Optional chip after the title reading "Statewide — WA", in ScopeChip geometry (24pt pill, surface.sunken fill, label 13/18 text.strong) with a 12pt state-outline glyph. It states coverage, not visibility.
⑧ Annual rows and self-entered rows: a 2px identity.home rule on the leading edge, full row height, plus a recurrence caption on the last line in caption text.secondary ("Every year", "Every month" or "Does not repeat").
⑨ Done tick: a 16pt stroke check before the title. It is a bare stroke, not a disc, so it cannot be mistaken for the YOU ADDED mark.
⑩ Web menu callout: "web menu: a row menu button (20px ellipsis, 44px target) after the mark, holding Edit · Remind me · Where this comes from · Mark done".

GREYSCALE (03 captions)

- kind = KindGlyph shape.

ACCESSIBILITY (panel)
- The whole row is one element and one target (minimum 56pt), read in visual order. The mark and the glyph are not targets.
- Spoken pattern: "<title>, <line 2 as shown>, <authority, scope>, <mark name>". The label speaks only the dates the row shows, so "Tomorrow" is spoken as "tomorrow" with no absolute date. Example: "Recycling and garbage, tomorrow, Waste Connections city schedule, on record, not confirmed."
- Done rows start with "You marked this done". Done stays Only you.
- Custom actions: Edit · Remind me · Where this comes from · Mark done. On web they sit in the ⑩ row menu button.
- Non-colour encoding: the glyph shape carries the kind, the mark shape carries provenance, the leading bar carries highlight, and the words carry done.
- Contrast: text at least 4.5:1; mark at least 3:1 (text.secondary on base, 4.83:1).

COPY RULES (panel)
- For deadlines, the title names the action: "Tell your landlord in writing by Mon 1 Mar 2027".
- Received-by deadlines say "must arrive by".
- Dates are spelled out with the weekday ("Mon 26 Oct"), never 10/26/2026.
- Beyond tomorrow, the relative count comes first: "in 7 days · Mon 26 Oct". Conditional rules (V4) are exempt from the relative count.
- Source captions carry a scope word: "Clark County Treasurer · county-wide".
- Pickup titles use exactly "Recycling and garbage" or "Garbage only".
- Holiday moves read "moved to Fri 27 Nov", never "delayed" or "cancelled".
- "I did this" reads "You marked this done" and stays Only you.

PLATFORMS (panel): No platform differences, except that web adds the ⑩ row menu button (R12).

INSTEAD OF (panel)
- Instead of red text or an overdue chip on an annual date that has passed, draw the next occurrence with its "Every year" caption. Annual dates never inherit overdue red.
- Instead of one generic calendar icon for every row, draw the specific KindGlyph. The glyph is what tells kinds apart without colour.
- Instead of a greyed placeholder row for a date the viewer may not see, draw nothing. A ghost row leaks that something exists.
- Instead of a numeric date like 10/26/2026, draw "Mon 26 Oct". The weekday is what people plan by.

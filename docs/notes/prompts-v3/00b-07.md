ANATOMY (on 01-anatomy, with a callout on every part)
- A vertical block, at most 160pt wide. The place file header and the keeper strip use the same geometry.
- Line 1: the integer in h3 20/28/600 text.primary (the contract gives only its weight, "label weight" = 600; the h3 size is a design choice, see Notes B), a 4pt gap, then "on file" in caption 12/16 text.secondary, sharing one baseline.
- Line 2, 6pt below line 1: category pips, one labelled pip for each category that has anything known, in this fixed order: Place · Dates · Money · People · Proof.
  - Pip: height = its text line height + 4pt (20pt at default), radius pill, surface.sunken fill, captionMedium 12/16/500 text.strong (9.37:1), 8pt horizontal padding, 4pt gaps. captionMedium is the board's weight-500 caption and scales as caption (AX5 43, 200% 24).

  - A pip is always a word, never a bare dot, so categories are carried by words, not colour.
- Unknown categories draw nothing (see INSTEAD OF).
- Target: the whole block is one target of at least 44pt (48dp on Android, 44px on web), extended beyond the visible block if needed. Tapping it opens the place file; inside x-place-file, it scrolls to the list.

- Contrast table on 01, R6 rows: text.primary on base · text · 4.5:1; text.secondary on base · text · 4.5:1; text.strong on sunken · text · 4.5:1. In dark mode, pips on a dark raised card use dark sunken #0F172A; pips on dark base use dark raised #1E293B (R5).

INSTEAD OF
- Instead of a closed five-segment ring with outlined empty segments, draw the integer and word pips for known categories only, because an empty slot reads as a task left undone.
- Instead of a progress bar, level or XP, draw the plain count, because the count states what is held, not how far someone has come.
- Instead of a count-up animation (in any state, including loading), show the final number at once, because motion here implies an achievement.
- Instead of "3 of 6 things on file", write "14 on file", because fractions imply incompleteness.
- Instead of different counts for the same home on different surfaces, show "14 on file" everywhere at the same moment, because drift reads as an error.
- Instead of the spoken "14 things on file", say "14 on file", because the spoken name must contain the visible text.
- Instead of greyed placeholder pips, outlines or "0" for unknown categories, draw nothing, because the host x-place-file owns any "You can also add" list; this component never draws one.

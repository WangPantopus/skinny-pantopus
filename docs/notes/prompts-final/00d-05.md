INSTEAD OF
- Instead of stacking an invite banner over a compare banner, draw only the ladder's winner — because two banners split attention and push content down.
- Instead of a red "Couldn't load invitations" banner on a fetch failure, render nothing — because a failed optional fetch must not look like an alert.
- Instead of an amber-tinted pill for expiry, draw "Expires tomorrow · Mon 26 Oct" in text.primary with the warning hue only on the glyph — because tinted text fails contrast and colour alone doesn't carry meaning.
- Instead of "You've been invited!", draw "Maya Chen invited you to Larkspur Loop" — because the actor comes first.
- Instead of a dead action while offline, keep it focusable with its reason read out and written — because silent dead buttons leave people guessing.

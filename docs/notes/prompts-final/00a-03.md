INSTEAD OF (print on 01-anatomy)
- Instead of a green "verified-looking" chip to mean membership, draw the neutral sunken chip with the house glyph — because green reads as verification, which is a different thing.
- Instead of dropping the chip from an alert landing, keep it next to the address — because an alert is when people most need to know who else sees it.
- Instead of "Everyone in this household" where finance permissions differ, name the people ("You and Sam can see these photos") — because the sentence would be false.
- Instead of an identity.home fill, use surface.sunken with text.strong — because the colour is not the message and fails contrast on sunken.
- Instead of any new wording, use the two chip strings and two sentences — because five earlier wordings drifted.
- Instead of a filled "Share" button beside an outlined decline, give both consent buttons the same secondary style — because a decline must carry equal weight.

PUBLISH NAME: FactRow. This message is the complete FactRow specification.

PURPOSE (print at the top of 01). One row per fact in the place file and in settings. The fact is known, missing, or not available at this tier.

USED IN (panel): x-place-file · f6-home-basics-rows · f1-today-tab · f3-household-block · f9-verification-promise-copy · f4-notification-settings.

ANATOMY (01-anatomy)
Draw three specimens at 2x, stacked: V1a (known, chevron), V2a (missing, "Add") and the ⑦ disclosure row.
① Row: minimum height 56pt, padding 16pt horizontal, on surface.base, content vertically centred.
② Label: bodySmall 14/20, text.secondary, above the value.
③ Value: body 16/24, text.primary.
④ ProvenanceMark S (16pt) after the value, with an 8pt (spacing.2) gap. It is not a target.
⑤ Trailing element: either a chevron (16pt, text.secondary) or a text action in bodySmallMedium primary.700 (dark: dark border.focus), e.g. "Add".
⑥ Missing form: the label, then an ask sentence in body text.primary, then the text action "Add".
⑦ Disclosure row "More you can add (5)" with a chevron, 44pt minimum. At most 3 promoted asks show per screen; the rest sit under this row.
⑧ Target rule callout. On rows with a chevron, the whole row is the target. On rows with a text action (missing, declined, permission-disabled), the text action is a separate 44pt / 48dp / 44px button and the row itself is not a target. Rows with neither (V3 and V8) are not targets. Draw the dashed target on each specimen accordingly: around the V1a row, and around "Add" only on V2a.
⑨ Web menu callout: "no custom actions; no row menu button".

ACCESSIBILITY (panel)
- Targets follow ⑧. A row with a chevron is one target (44pt / 48dp / 44px; 56pt visual). A text action is a separate button, and its row is not a target.
- Known rows merge their label: "<label>, <value>, <mark name>". Example: "Flood zone, Zone X, minimal flood hazard, official."
- Asks are read as text, then a verb-first button: "Pickup frequency, not set." then "Add. Button."
- V5a is announced with role=status ("Just you, then. Undo."), and Undo is focusable.
- The loading skeleton is announced once as "Loading".
- A disabled offline action reads its reason as a hint.

COPY RULES (panel)
- The approved asks are "Set your pickup day" · "Add one date that matters" · "Add the people you live with".
- "Not set" is in text.secondary.
- Hazard values put the plain meaning first: "Zone X — minimal flood hazard".
- Declines are neutral: "Just me", "Skipped".
- Offline reasons open with "You're offline".

PLATFORMS (panel): No platform differences.

INSTEAD OF (panel)
- Instead of a red X or red text for a missing fact, draw the ask sentence with "Add". Missing is an invitation, not an error.
- Instead of a score, percentage or "3 of 6" on the place file, draw plain rows and the "More you can add (5)" disclosure. Counts of completion create pressure.
- Instead of more than 3 promoted asks, draw 3 and fold the rest under "More you can add (5)".
- Instead of hiding a not-at-tier fact, draw it grey with "Claim this address first" and no button, so the path is named without a dead control.

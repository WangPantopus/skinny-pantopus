ACCESSIBILITY (print on 01-anatomy)
- Changes are announced in a polite live region, never an assertive one (iOS: an accessibility announcement queued behind current speech (default or low priority); Android: accessibilityLiveRegion="polite"; web: aria-live="polite").
- Non-colour: stale is stated in words.
- Target rule: Retry is a target (B13).
- Ageing text is announced once, not every minute.
- Spoken example: "You're offline, as of 7:04 AM".

COPY (print on 01-anatomy)
- Relative time for recency ("Updated 12m ago"). "As of" plus an absolute time for offline or frozen data ("as of 7:04 AM"); add the weekday only when the time is not today.
- Never "Last synced", "refreshed at" or "last seen".
- Never a disappearing toast as the only proof.

INSTEAD OF (print on 01-anatomy)
- Instead of dimming, skeletoning or reflowing a warm screen while refreshing, keep it and show "Updating…" (and the hairline after 1s) — because stale content is still useful.
- Instead of a hairline that loops until the request ends, stop it at 5s and leave "Updating…" — because idle loops stop within 5s.
- Instead of a custom animated hairline, use the platform's system indeterminate indicator — because a custom loop is a motion spec nobody needs to maintain.
- Instead of greying a whole widget when only AQI is old, put the age words on the air line — because the other facts are still current.
- Instead of a toast, use this line — because toasts vanish before people read them.
- Instead of "Last synced", write "Updated" or "As of" — because "synced" is jargon.

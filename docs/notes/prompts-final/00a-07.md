ACCESSIBILITY (print)
- Decorative (hidden) when a text label is adjacent; otherwise labelled with the row label ("Recycling"). Always paired with visible text; widget and tray glyphs carry their word.
- Each tile is one element: "Pickup day, selected, 1 of 10" (iOS: a button with the selected trait; Android: RadioButton semantics; web: role="radio" inside role="radiogroup").
- Non-colour: shape plus label; selection is the dot or check plus the edge, fill and ink change.
- Target: the tile cell or row, never the glyph alone (B13).

COPY (print)
- Tile labels, exactly: Pickup day · Move-in date · Lease ends · Notice deadline · Insurance renews · Warranty ends · HOA dues · Property-tax appeal · Voter registration · Bill.
- Row labels, exactly: the "row label" column of THE SET. The ones with no tile are Garbage · Recycling · Recycling and garbage · Bulk pickup · Property-tax due · Home date · Task · Package.
- "Pickup day", never "trash day", "garbage day" or "bin day"; "Date", never "event" or "deadline item".

PLATFORMS (print)
- The same glyph on all three platforms. The widget glyph is silhouette-safe like ProvenanceMark: one ink, inner detail cut out, so it survives one-colour accented rendering.
- The one-column large-text list: a trailing check on iOS and web; Material 3 radio buttons on Android.

INSTEAD OF (print)
- Hue-coded glyphs as the only class cue → a silhouette per kind plus a label, because hue alone fails in greyscale and for colour-blind users.
- An unlabelled glyph → the kind's row label beside it, because the glyphs are not universal.
- Guessing a tile's glyph → the TILE → GLYPH map, because every later picker copies this one.
- Selection shown with the focus ring → fill + edge + radio dot + label ink, because selection must look different from focus.
- An empty-ring radio on iOS or web large-text rows → a trailing check on the selected row and nothing on the others, because iOS has no radio control and an empty ring is the unconfirmed mark's shape.
- Emoji or a second icon set → the Pantopus icon style, because the house style forbids a new icon set.

INSTEAD OF
- Instead of "Are you sure?" / "OK" / "Cancel", draw "Delete this photo?" / "Delete photo" / "Keep it" — because people decide faster when the buttons say what happens.
- Instead of "This can't be undone", draw the sentence naming what stays — because people fear losing more than they will.
- Instead of a filled red button, a red slab above the content, or red label text, draw the outlined button with a semantic.error border, the glyph and a text.primary label — because a red fill shouts, semantic hues go on glyphs and borders only, and red text drops below readable contrast in dark mode.
- Instead of default focus on the destructive button, put keyboard focus on Keep — because Enter must never destroy something.
- Instead of this dialog for a cheap removal, use InlineUndo — because dialogs are only for losses that can't be undone.

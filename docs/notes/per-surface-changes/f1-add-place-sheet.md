# Research-backed changes for f1-add-place-sheet

- When geocoding fails: 'Can't find it? Enter it line by line' (street, city, ZIP) in the same detent [competitive]
- Replace the Clark-County-only refusal: save the address and say which layers exist there [competitive]
- Rank suggestions by proximity and tolerate typos [competitive]
- Duplicate address: a selectable existing row ('Already saved — open it'), no retype [onboarding]
- A caption under the field: 'We use the address you type — no location access' [competitive]
- The entry label is 'Add a place' / 'Save an address', never 'Preview an address' [onboarding]
- Visible Close; the field uses address autocomplete; add an AX5 frame [a11y]

Keep 'Preview an address' only for an entry that actually goes to the /start preview. Update f1-today-tab's frame 1 copy to match.

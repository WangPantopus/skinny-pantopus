# Research-backed changes for f3-household-block

- Pair 'Not now' (never shown again automatically) with a full-weight 'Just me' that persists server-side, can be undone, and has a way back through the roster [onboarding, household]
- At T1 the block is a grey 'Claim this address first' with no CTA [onboarding]
- The copy is a verb-first ask: 'Add the people you live with'. 'Just me' leads to a completed state with no badge or 'missing' count [household]
- Turning on household activity is one of the permission triggers; the undo stays until the user leaves the screen [notifications, a11y]

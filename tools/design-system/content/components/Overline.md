The uppercase section label: 11px, weight 600, 0.06em tracking, `app-text-secondary`.

**Provide:** `children` (a short noun phrase, typed in sentence case; CSS uppercases it), optional `as` (`span` default, `div`, `p`, `h2`, `h3`) and `className`.

Use it above groups of content, never as a heading replacement for a whole page. Native: the `overline` text style; iOS requires `Text(copy, style: .overline)` and Android callers uppercase the string. Source: `frontend/apps/web/src/components/archetypes/primitives/Overline.tsx`.

# Logos

The perforation mark and its compositions, drawn from the canonical geometry in `PantopusMark.tsx`. Colors are written into each file because an `<img>` can't inherit them.

- `pantopus-mark.svg`: the mark for light grounds. Body {{hex:color-primary-600}} (`color-primary-600`), check {{hex:color-brand-check}} (`color-brand-check`).
- `pantopus-mark-dark.svg`: the mark for dark grounds. Body {{hex:color-primary-400}} (`color-primary-400`), check {{hex:color-brand-check}}.
- `pantopus-favicon.svg`: the shipped favicon (`public/favicon.svg`). The small-size plug replaces the check, body {{hex:color-primary-600}}. Use this form at 20px and below.
- `pantopus-app-icon.svg`: the launcher tile. The white reverse mark on {{hex:color-primary-600}} with the body spanning 9/16 of the tile; each platform masks the corners.
- `pantopus-icon-512.png`: the shipped 512px web app icon (`public/icon-512.png`), the same composition as a raster.
- `pantopus-lockup.svg`: mark plus the "Pantopus" wordmark for light grounds. The word is live bold system-font text in {{hex:app-text}} (`app-text`), so it renders in the viewer's UI font, as it does in the product.
